# Firstline

An agent team that triages new GitHub issues: type, completeness, duplicates,
labels, likely fix location and a cited first reply, with every decision logged,
scored for confidence and routed to a human when it isn't sure.

**Status:** under construction. Nothing here has been evaluated yet, so there
are no results to report. See [`docs/design.md`](docs/design.md) for the design.
